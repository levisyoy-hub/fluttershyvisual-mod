ВАРИАНТ 1: Автоматическая загрузка (Windows PowerShell)
═════════════════════════════════════════════════════════════════

1. Откройте PowerShell
2. Выполните:

   cd c:\Users\Admin\Desktop\fsv
   .\github-upload.ps1

3. Введите GitHub логин и Personal Access Token (PAT)
   https://github.com/settings/tokens/new?scopes=repo,workflow

4. Ждите сборки на https://github.com/YOUR_LOGIN/fluttershyvisual/actions

───────────────────────────────────────────────────────────────

ВАРИАНТ 2: Ручная загрузка
═════════════════════════════════════════════════════════════════

1. Создайте репозиторий на GitHub:
   https://github.com/new
   - Name: fluttershyvisual
   - Visibility: Public

2. В PowerShell выполните:

   cd c:\Users\Admin\Desktop\fsv
   
   $login = "YOUR_GITHUB_LOGIN"
   $token = "YOUR_PAT_TOKEN"
   
   $git = "C:\Program Files\Git\bin\git.exe"
   &$git remote add origin "https://$login`:$token@github.com/$login/fluttershyvisual.git"
   &$git branch -M main
   &$git push -u origin main

3. Ждите сборки: https://github.com/$login/fluttershyvisual/actions

❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ:
═════════════════════════════════════════════════════════════════

Q: Как получить GitHub Personal Access Token (PAT)?
A: https://github.com/settings/tokens/new
   - Выберите scopes: repo + workflow
   - Скопируйте токен (используйте сразу!)

Q: Сборка падает с ошибкой - что делать?
A: Проверьте:
   - Правильный GitHub токен
   - Репозиторий создан на GitHub
   - Интернет соединение

Q: Сборка долго - это нормально?
A: Да! Первая сборка может занять 10-15 минут
   Последующие - 5-10 минут

Q: Где найти мой GitHub логин?
A: https://github.com/settings/profile
   Это ваше имя пользователя в URL
