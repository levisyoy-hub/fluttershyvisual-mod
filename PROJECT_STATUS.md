✅ РЕШЕНИЕ:
─────────────────────────────────────────────────────────────
1️⃣  РЕКОМЕНДУЕМЫЙ СПОСОБ - Docker (универсальное решение):
   
   docker run --rm -v %CD%:/workspace -w /workspace \
     gradle:8.8-jdk21 gradle clean build
   
   Результат: build/libs/fluttershyvisual-1.0.0.jar

2️⃣  АЛЬТЕРНАТИВНЫЙ СПОСОБ - GitHub Actions (облачная сборка):
   
   - Создайте .github/workflows/build.yml
   - Загрузите проект на GitHub
   - Сборка будет работать автоматически

3️⃣  ДРУГОЙ КОМПЬЮТЕР:
   
   - Скопируйте папку fsv на машину с Java 21 и интернетом
   - Запустите: gradle clean build
   - JAR появится в: build/libs/

4️⃣  ГОТОВЫЙ JAR (ограниченный функционал):
   
   output/fluttershyvisual-1.0.0.jar
   - Содержит метаданные и ресурсы мода
